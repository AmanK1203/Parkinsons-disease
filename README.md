# 🧠 Parkinson's Disease Prediction Using Deep Learning

A Deep Learning and Machine Learning project for predicting Parkinson's Disease using **hand-drawn spiral/wave images** and **audio-based acoustic features**.

The project evaluates multiple deep learning architectures for image classification, including **VGG16, ResNet50, DenseNet121, and a Custom CNN**, along with machine learning approaches for audio-based prediction.

A user-friendly **Streamlit web application** is also developed to allow users to upload an image and obtain a prediction.

> ⚠️ **Disclaimer:** This project is developed for educational and research purposes only. The predictions generated by this system should not be considered a medical diagnosis or a substitute for professional medical advice.

# 📌 Project Overview

Parkinson's Disease is a progressive neurological disorder that can affect movement and other functions.

This project explores the use of **Deep Learning and Machine Learning techniques** to identify patterns associated with Parkinson's Disease using two different types of data:

### 🖼️ Image-Based Data

The image-based approach uses hand-drawn:

- Spiral drawings
- Wave drawings

The images are classified into two categories:

- **Healthy**
- **Parkinson's**

Multiple deep learning architectures are trained and evaluated to determine their performance on the image classification task.

### 🎙️ Audio-Based Data

The project also explores Parkinson's Disease prediction using voice/audio data.

Acoustic features are extracted from voice recordings, including:

- MFCC
- Chroma
- Zero-Crossing Rate
- Other acoustic features

These features are then used to train machine learning classification models.
